¿Qué es Kanban?

Kanban es una metodología para gestionar y organizar el trabajo de forma visual. Las tareas se representan mediante tarjetas y avanzan por diferentes etapas de un proceso.

POR HACER
→
EN PROCESO
→
TERMINADO
👁️

Visualizar

Permite ver qué tareas existen y en qué estado se encuentran.

📋

Organizar

Ayuda a ordenar el trabajo y establecer prioridades.

🔄

Mejorar

Facilita detectar problemas y mejorar el flujo de trabajo.

Elementos principales

🗂️

Tablero

Representa visualmente el flujo de trabajo mediante columnas.

📝

Tarjetas

Cada tarjeta representa una tarea o actividad.

📊

Columnas

Representan las etapas por las que pasa una tarea.

🚦

Límite de trabajo

Ayuda a evitar que se acumulen demasiadas tareas en proceso.

Principios de Kanban

1. Visualizar el trabajo

Mostrar las tareas en un tablero para conocer el estado del trabajo.

2. Limitar el trabajo en progreso

Evitar comenzar más tareas de las que el equipo puede atender.

3. Gestionar el flujo

Observar cómo avanzan las tareas y detectar retrasos.

4. Hacer explícitas las reglas

Definir claramente cuándo una tarea puede pasar de una etapa a otra.

5. Mejorar continuamente

Analizar el proceso y realizar cambios para hacerlo más eficiente.

Ejemplo: proyecto escolar
